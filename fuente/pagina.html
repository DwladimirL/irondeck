Cómo funcionaHow it works

IronDeck es un programa para tu PC que dirige a Claude Code, el agente de programación de Anthropic. Lo armé para avanzar proyectos largos sin estar frente a la pantalla.IronDeck is a program for your PC that drives Claude Code, Anthropic's coding agent. I built it to move long projects forward without sitting at the screen.

Usa tu propio Claude Code y tu propio plan de Claude. No hay un servidor de IronDeck en medio.It uses your own Claude Code and your own Claude plan. There is no IronDeck server in between.

  1. Describes el trabajo por pasosYou describe the work in steps

    Por ejemplo: investigar, diseñar, construir y revisar. Cada paso usa el modelo de Claude que le conviene: uno ágil para leer, uno más fuerte para construir.For example: research, design, build and review. Each step uses the Claude model that fits it: a quick one for reading, a stronger one for building.

  2. IronDeck lo pone en marchaIronDeck sets it running

    Lanza Claude Code en tu PC, cada tarea en su propia copia del proyecto para que no se pisen, hasta cuatro a la vez.It runs Claude Code on your PC, each task in its own copy of the project so they don't collide, up to four at once.

  3. Te pregunta solo lo necesarioIt only asks what it must

    Si algo necesita tu decisión, espera en la bandeja y te llega un aviso de Windows. Respondes y sigue.When something needs your call, it waits in the inbox and you get a Windows notification. You answer, it carries on.

  4. Apruebas lo terminadoYou approve the finished work

    Los cambios entran a tu proyecto solo cuando das el visto bueno.Changes reach your project only when you give the go-ahead.

  5. Tus skills, con historialYour skills, with history

    Las instrucciones que le enseñan a Claude a trabajar a tu manera quedan guardadas con todas sus versiones.The instructions that teach Claude to work your way are kept with every version.

Flujos por pasosStep-by-step flows

Con el modelo, el esfuerzo y los permisos de cada paso. Corren en orden; que cada paso reciba lo que entregó el anterior llega en la fase actual.With the model, effort and permissions for each step. They run in order; handing each step what the previous one delivered comes in the current phase.

Retoma soloPicks itself back up

Si cierras el programa o se apaga la PC, al volver repite el paso que quedó a medias; lo terminado no se pierde. Si una tarea falla, la reintenta con un modelo más fuerte, si lo hay.If you close the app or the PC shuts down, it reruns the interrupted step when you return; finished work isn't lost. If a task fails, it retries with a stronger model, when there is one.

Plan y cobroPlan and billing

Límites del planPlan limits
Lee los avisos de límite que Claude Code emite durante la tarea: porcentaje usado y hora de reinicio, de las 5 horas y de la semana. Un límite pausa; no cuenta como fallo.Reads the rate-limit events Claude Code emits during the task: percentage used and reset time, for the 5-hour window and the week. A limit pauses; it doesn't count as a failure.
CobroBilling
Antes de lanzar, comprueba con qué cuenta corre Claude Code; no usa claves de API. Dos modos: «solo plan», que corta la tarea si Claude Code informa uso extra, y «plan + uso extra», que lo permite hasta un tope en dinero (llega antes del lanzamiento).Before launching, checks which account Claude Code runs under; it doesn't use API keys. Two modes: plan only, which stops the task if Claude Code reports extra usage, and plan plus extra usage, which allows it up to a spending cap (arrives before launch).
FallosFailures
Falla una tarea que termina con error o con la entrega a medias: la reintenta una vez con un modelo mayor, si lo hay, y al segundo fallo decides tú. Un permiso negado la detiene sin reintentar. Máximo de 6 horas por tarea.A task fails when it ends with an error or a partial delivery: it gets one retry with a larger model, when there is one, and on a second failure you decide. A denied permission stops it without a retry. 6-hour maximum per task.

Un proceso aparte actualiza con el programa cerrado y vuelve a la versión anterior si la nueva no arranca.A separate process updates with the app closed and rolls back if the new version doesn't start.

PruebasTests

Todavía no:Not yet: pasar el resultado de un paso al siguiente, el modo con uso extra y la capa autónoma. Están en la hoja de ruta.passing one step's result to the next, the extra-usage mode, and the autonomous layer. All are on the roadmap.

Preguntas frecuentesFrequently asked questions

¿Qué necesito para usarlo?What do I need to use it?

Una PC con Windows, Claude Code instalado con tu cuenta y un plan de Claude que lo incluya: Pro o Max, o un plan Team o Enterprise. Además, Git y Node.js. La lista final sale con la primera versión.A Windows PC, Claude Code installed with your account, and a Claude plan that includes it: Pro or Max, or a Team or Enterprise plan. Also Git and Node.js. The final list ships with the first release.

¿Necesito saber programar?Do I need to know how to code?

No para usarlo: describes el trabajo y apruebas el resultado. Sí ayuda para revisar lo que entrega, igual que con Claude Code solo.Not to use it: you describe the work and approve the result. It does help when reviewing what it delivers, just as with Claude Code on its own.

¿Puede romper algo en mi PC?Can it break something on my PC?

Cada tarea trabaja en una copia de tu proyecto y solo puede usar las herramientas que permite su paso. Sus cambios entran a tu proyecto cuando los apruebas, pero los comandos que permitas, como publicar o instalar paquetes, actúan fuera de esa copia. Es una versión en desarrollo: úsala con Git y copias de seguridad.Each task works in a copy of your project and can only use the tools its step allows. Its changes reach your project when you approve them, but commands you allow, such as publishing or installing packages, act outside that copy. It's a version in development: use it with Git and backups.

¿Qué cuenta usa?Which account does it use?

La tuya. IronDeck lanza tu propia instalación de Claude Code en tu PC. No te pide iniciar sesión, no guarda tu contraseña y no pasa tu sesión por ningún servidor. Lo que gasta sale de tu plan y, solo si lo activas, del uso extra de tu cuenta.Yours. IronDeck runs your own Claude Code installation on your PC. It doesn't ask you to sign in, doesn't store your password, and doesn't route your session through any server. What it uses comes out of your plan and, only if you turn it on, your account's extra usage.

¿Puede gastar más allá de mi plan?Can it spend beyond my plan?

Solo si tienes activado el uso extra en tu cuenta de Anthropic; sin él, no puede. Si lo tienes activado, por defecto IronDeck detiene la tarea en cuanto Claude Code informa uso extra, y lo consumido hasta ese aviso se cobra. Si prefieres que no se detenga, podrás activar el uso extra de tu cuenta con un tope en dinero; ese modo llega antes del lanzamiento. Además decides cuánto de tu semana usa IronDeck.Only if extra usage is turned on in your Anthropic account; without it, it can't. If it is on, IronDeck stops a task by default as soon as Claude Code reports extra usage, and what was used up to that point is billed. If you'd rather it not stop, you'll be able to turn on your account's extra usage with a spending cap; that mode arrives before launch. You also decide how much of your week IronDeck uses.

¿Qué sale de mi PC?What leaves my PC?

IronDeck no tiene un servidor en internet: su servidor corre solo en tu PC. Sale lo que Claude Code envía a Anthropic al trabajar, las consultas a GitHub para buscar actualizaciones, lo que hagan tus tareas con los permisos que les des y, cuando llegue esa función, el respaldo de tu biblioteca en tu propia cuenta de GitHub. Nada de eso pasa por mí.IronDeck has no server on the internet: its server runs only on your PC. What leaves is what Claude Code sends to Anthropic while working, checks to GitHub for updates, whatever your tasks do with the permissions you grant them and, once that feature lands, the backup of your library to your own GitHub account. None of it goes through me.

¿IronDeck es de Anthropic?Is IronDeck made by Anthropic?

No. Es un proyecto independiente que trabaja con Claude Code. Anthropic no lo patrocina ni lo respalda.No. It's an independent project that works with Claude Code. Anthropic doesn't sponsor or endorse it.

¿Cuándo sale y cuánto cuesta?When does it ship, and what does it cost?

Todavía no tiene fecha ni precio. No cobro nada por adelantado, y la lista de espera se entera primero.There's no date or price yet. I don't charge anything in advance, and the waitlist hears first.

¿Funciona en Mac o Linux?Does it run on Mac or Linux?

Por ahora, solo en Windows.For now, Windows only.

¿El código es abierto?Is the code open source?

Por ahora es privado. Este sitio y su repositorio muestran el avance, las guías y las novedades.It's private for now. This site and its repository show the progress, the guides and the updates.
